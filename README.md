# 基礎專業英語｜期中聽力練習器

👉 **直接開始練習：https://pangibson666.github.io/English-1-1-Midterm-Exams/**

講義上有題目的聽力音檔，配上逐字稿（含中文翻譯）、題目、自動對答案和中文解析。手機、電腦都可以用，不用登入。

## 內容

| 單元 | 內容 |
|---|---|
| ★ Phoning for Directions | 交通工具排序、選擇題、找錯並更正（找錯／默寫／看答案三種模式） |
| Train Announcements | 選擇題、表格、填空 |
| Kings Place Tennis Courts | 筆記填空（ONE WORD AND/OR A NUMBER） |
| Listening for the Gist | Preview Test Q1–12（含座位圖） |
| Exercise 3.3／3.5／3.8 | 概述題、細節題、推論題 |
| Exercise 3.1 & 3.2 | 單字配對：地點、職業（無音檔） |
| 補充 | Exercise 3.4、3.6、3.7、IELTS Library Membership（講義沒附題目，只有逐字稿） |

## 怎麼用

1. 先開「盲聽」模式，只聽音檔作答
2. 對答案、看解析，按「📍聽原文」跳到出處重聽
3. 把每段逐字稿讀完，按「標記已讀」，首頁可以看到整體進度和錯題本

- 播放時會自動標出正在念的句子，點任何一句就從那句開始播
- 中文翻譯可以開關，播放速度可以調（0.75×～1.25×）
- 電腦快捷鍵：空白鍵 播放／暫停，← → 倒退／快轉 3 秒

## 注意

- 進度存在你自己的瀏覽器裡，換裝置、換瀏覽器或清除瀏覽資料就會不見。
- 逐字稿是用語音辨識產生，再逐句人工校對的。如果發現錯字，歡迎告訴我。
