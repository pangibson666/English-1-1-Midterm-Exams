# 基礎專業英語｜期中聽力練習器

講義上有題目的聽力音檔，配上逐字稿（含中文翻譯）、題目、自動對答案和中文解析。

## 內容

| 單元 | 內容 |
|---|---|
| ★ Phoning for Directions | 交通工具排序、選擇題、找錯並更正（找錯／默寫／看答案三種模式） |
| Train Announcements | 選擇題、表格、填空 |
| Kings Place Tennis Courts | 筆記填空（ONE WORD AND/OR A NUMBER） |
| Listening for the Gist | Preview Test Q1–12（含座位圖） |
| Exercise 3.3／3.5／3.8 | 概述題、細節題、推論題 |
| Exercise 3.1 & 3.2 | 單字配對：地點、職業（無音檔） |
| 補充 | Exercise 3.4、3.6、3.7、IELTS Library Membership（只有逐字稿） |

## 功能

- 播放時自動標出正在念的句子，點任何一句就從那句開始播
- 中文翻譯可開關；「盲聽」模式會把逐字稿模糊掉
- 每題都有中文解析，按「📍聽原文」直接跳到出處
- 每段逐字稿可以「標記已讀」，首頁看得到整體進度和錯題本
- 進度存在自己的瀏覽器裡（換瀏覽器或清除瀏覽資料就會不見）
- 快捷鍵：空白鍵 播放／暫停，← → 倒退／快轉 3 秒

## 怎麼打開

**方法一：GitHub Pages（推薦，手機也能用）**
1. 把這個資料夾的檔案上傳到一個 GitHub repository
2. 到 repository 的 **Settings → Pages**
3. Source 選 **Deploy from a branch**，Branch 選 `main`、資料夾選 `/ (root)`，按 Save
4. 等一兩分鐘，網址會顯示在同一頁（像 `https://你的帳號.github.io/repo名稱/`）

**方法二：直接在電腦開**
下載整個資料夾（`index.html` 要和 `audio` 資料夾放在一起），用 Chrome 或 Edge 打開 `index.html`。

## 注意

逐字稿是用語音辨識產生、再逐句人工校對的，如果發現錯字歡迎提出。
